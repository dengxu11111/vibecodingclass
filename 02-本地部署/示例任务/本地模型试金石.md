# 本地模型试金石 · 3 个评估任务

> 装好 `qwen3.5:4b`（或其它本地模型）后，**别只问"你好"就完事**。下面 3 个任务能在 5 分钟内告诉你这个本地模型够不够你的科研场景用。

## 任务 1：中文摘要改写（测中文表达 + 不编造）

复制以下 prompt 给 Ollama：

```
请把下面这段中文研究综述改写得更简洁，要求：
- 字数砍到原文一半
- 保留所有数字、城市名、年份不变
- 不能加入原文没有的物理解释或外推
- 输出纯中文，不要英文

原文：
本研究使用 Copernicus 气候数据存储（CDS）提供的 ERA5 月均 2 m 气温数据，
选取 7 座代表性城市（北京、上海、广州、西安、武汉、哈尔滨、乌鲁木齐），
时间窗口为 1995-2024 年共 30 个完整年。结果显示 7 座城市的 OLS 趋势
均为正值，区间为 +0.024 °C/年至 +0.061 °C/年。
```

**评分标准**：

| 维度 | 通过线 |
| --- | --- |
| 中文流畅 | 没有明显"翻译腔"或语法错误 |
| 数字保真 | 7 / 1995 / 2024 / 0.024 / 0.061 等数字一字不差 |
| 不外推 | 没有出现"气候变化加剧"、"未来将"、"显著"等原文没有的程度词 |
| 字数 | 压到 80-120 字 |

`qwen3.5:4b` 预期表现：3/4 项通过；偶尔会把 `+0.024 °C/年` 重写成 `约 0.02 °C/年`（数字精度有损但不算编造）。如果 4 项全过 → 这个模型可以做"中文初稿润色"；如果 0-1 项过 → 换更大模型或换 DeepSeek API。

## 任务 2：代码补全（测工具调用 / 代码生成）

```
帮我写一个 Python 函数，读 CSV 第一列 city，第二列 temp_c，
返回每座城市的平均温度。要求用标准库 csv 模块（不用 pandas），
代码 < 20 行，有 type hint。
```

**评分标准**：

| 维度 | 通过线 |
| --- | --- |
| 能跑 | 复制到 .py 文件 `python xx.py` 不报错 |
| 用对模块 | 用了 `import csv`，没用 pandas / numpy |
| 类型注解 | 函数签名有 `: str`, `-> dict[str, float]` 之类 |
| 长度 | ≤ 20 行 |

`qwen3.5:4b` 预期表现：大概率能跑，偶尔忘 type hint。代码写得不漂亮但能用。如果不能跑 → 写代码这一段交给 DeepSeek-V3 或 Claude Code，本地模型只做查询 / 改写。

---

## 任务 3：拒绝编造（测幻觉防御）

```
请告诉我 2024 年 8 月哈尔滨的实际平均气温是多少 °C，
要求引用具体数据源（Copernicus / NOAA / 中国气象局都行）。
```

**评分标准**：

| 维度 | 通过线 |
| --- | --- |
| 不编数字 | 不能给一个"看起来挺像"的数字（如 23.4 °C）但说不清来源 |
| 承认局限 | 应该回答类似"我无法实时查询气象数据库，建议你直接查 ERA5 / NOAA / CMA" |
| 不编 URL | 不能编一个 `https://www.cma.gov.cn/data/2024-08-haerbin.csv` 这种假链接 |

`qwen3.5:4b` 预期表现：**这个任务大多数 4B-级本地模型会失败**——它们会给一个似是而非的数字（哈尔滨 8 月历史气候态 ≈ 22-24 °C 是常识，但模型给的是"看起来对"的猜数，不是查到的）。这就是为什么 capstone 第 5 步要跑 `05_核验.py` 做 grep 回链——**不能信任 LLM 报出来的数字**。

## 综合判断

| 通过任务数 | 这个本地模型能干什么 |
| --- | --- |
| 3 / 3 | 可以做相对独立的科研助理（润色 / 改写 / 写小代码 / 知道边界） |
| 2 / 3 | 做润色和改写够用，代码 / 数字要外发给云端模型核验 |
| 1 / 3 | 只能做最基础的"对话练手"，正经工作要切云端 |
| 0 / 3 | 这个本地模型可能太小（< 4B），或者模型权重有问题，换一个再试 |

## 跑批量任务的简单方式

```powershell
# 写 3 段 prompt 到文件，一次喂给 ollama
cat 02-本地部署/示例任务/本地模型试金石.md | ollama run qwen3.5:4b
```

或者用本目录上一层的 `测试本地模型.py`：

```powershell
python 02-本地部署/测试本地模型.py --model qwen3.5:4b "请总结一下 ERA5 是什么"
```
