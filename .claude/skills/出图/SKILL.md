# 出图

## 何时使用

当用户需要把表格数据、实验结果或论文统计结果做成可读图表时使用，尤其适合折线图、柱状图、散点图、箱线图和简单分组对比图。

## 输入

- 数据文件路径或 DataFrame 说明
- 图表类型
- x 轴、y 轴、分组字段
- 输出格式，例如 PNG、PDF 或 SVG
- 是否用于论文、汇报或演示

## 工作流程

1. 先检查数据字段、缺失值和可用样本量。
2. 根据目标选择合适图表，不确定时先给出 2 个备选方案。
3. 使用清晰标题、轴标签、图例和单位。
4. 导出图片到 `outputs/` 或用户指定目录。
5. 简要说明图中最值得注意的趋势或异常。

## 默认风格

- 图像宽高适合投影或文档阅读。
- 不使用过多颜色，默认 4 个分组以内。
- 中文标题和标签需要确认字体可用；不确定时优先用英文标签避免乱码。
- 保留生成图片所用的脚本或 Notebook 单元。

## 输出格式

- 图像文件路径
- 生成图表的代码位置
- 图表解读要点
- 可能影响结论的数据限制

## 验收

- 图片文件存在且可以打开。
- 坐标轴、单位和图例完整。
- 图表能回答用户提出的问题。
- 结论没有超出数据能支持的范围。
