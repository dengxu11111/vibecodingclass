# 数据清洗

## 何时使用

当用户需要清洗 CSV、Excel 或表格型数据时使用，例如去重、补齐缺失值、统一列名、转换日期、筛选异常值、排序和导出干净数据。

## 输入

- 数据文件路径
- 需要保留或重点处理的字段
- 清洗规则，例如去重键、日期列、缺失值处理方式
- 期望输出路径或文件格式

## 工作流程

1. 先读取数据并报告行数、列数、字段名和明显异常。
2. 在不覆盖原始文件的前提下执行清洗。
3. 对每一步清洗记录前后变化，例如删除多少重复行、补齐多少缺失值。
4. 输出清洗后的文件，并生成一段简短的数据质量摘要。

## 默认规则

- 原始文件只读，不直接改写。
- 日期列统一为 ISO 格式 `YYYY-MM-DD`。
- 列名默认转为简洁中文或 snake_case，具体按用户要求。
- 不确定的异常值先标记，不擅自删除。

## 输出格式

- 清洗后的文件路径
- 清洗动作列表
- 数据质量摘要
- 仍需人工确认的问题

## 验收

- 输出文件可以被重新读取。
- 行数、列数变化有说明。
- 原始数据没有被覆盖。
- 至少给出 3 条数据质量观察，除非数据为空。
