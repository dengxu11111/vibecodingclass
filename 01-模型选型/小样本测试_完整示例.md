# 小样本测试 · 完整示例

> [小样本测试模板.md](./小样本测试模板.md) 填完之后长这样。先看一遍，再填自己的。

## 任务

```
任务名：中文气候综述 → 英文标题 + 3 句要点
输入：200-500 字中文综述
产出：
  - 1 行英文标题 (≤ 15 词)
  - 3 句英文要点 (各 ≤ 25 词)，覆盖 方法 / 主要发现 / 局限
判定：
  - 数字不外推，不能编 csv 里没有的城市 / 年份
  - 英语学术风格 (被动 + 名词化)，无中式英语
  - 标题不超字数
```

## 候选模型 + 统一 prompt

```
候选 A：DeepSeek-V3        # 国产、便宜、中文强
候选 B：Claude Sonnet 4.6  # 学术英语金标准
候选 C：DeepSeek-R1        # 推理型，看会不会"想太多"
```

统一 prompt（替换 `{INPUT}`），温度 0.2：

```
你是科研英语翻译助手。读下面这段中文综述，输出：
1. 英文标题（≤ 15 词）
2. 3 句英文要点（各 ≤ 25 词），分别覆盖：(a) 方法 (b) 主要发现 (c) 局限

硬约束：不许出现原文没有的数字 / 城市 / 年份；英语学术风格无中式英语。
输出格式：Title: ... \n Point 1 (method): ... \n Point 2 (findings): ... \n Point 3 (limits): ...

原文：{INPUT}
```

## 打分

|  | DeepSeek-V3 | Sonnet 4.6 | DeepSeek-R1 |
| --- | --- | --- | --- |
| 准确率 | 3.5 / 5（s2 掉陷阱、s4 英化不彻底） | 5 / 5 | 4.5 / 5（s3 标题略长） |
| 速度（s / 样本） | 2-3 | 4-6 | 8-15 (含思考链) |
| 单条成本 | ~$0.0003 | ~$0.005 | ~$0.0015 |
| 总评 | 便宜快但易被陷阱误导 | 学术英语稳，贵 17× | 推理稳但慢 |

## 结论沉淀

```
任务【中文综述 → 英文标题 + 要点】：
  首选 = Claude Sonnet 4.6（抗 hallucination 强）
  备选 = DeepSeek-R1（预算紧时）
  不选 = DeepSeek-V3（s2 掉陷阱，不适合给导师看的产物）

折中：V3 起草 → Sonnet 改写一次（成本 ≈ Sonnet 单走的 1/3）
     这就是 capstone 第 09 章多模型协作的雏形

→ 写进 资源/常用prompt模板.md
```
