# 第 01 章 · 验收清单

> 对应 PPT 第 16 页 SUMMARY。打勾就算掌握了。

## Token 估算规则

- [ ] 能跑通 `python token估算.py "测试文本"`，看懂输出的 token 数和费用
- [ ] 能解释为什么"中文 1 字 ≈ 1 token、英文 1 word ≈ 1.3 token"
- [ ] 知道推理模型的输出 token 包含"思考链"，比普通模型贵

## API 成本样例

- [ ] 能在 [模型对比表.md](./模型对比表.md) 里找出 DeepSeek-V3 和 Claude Opus 4.7 的输入价差
- [ ] 能估算"一篇 2 万字论文 + 5K 字总结"的总费用
- [ ] 知道国产模型 / 国外模型怎么挑：便宜 → DeepSeek，推理 → R1，工具调用 → Claude

## 国产模型对比清单

- [ ] 能说出至少 4 家国产大模型（DeepSeek / 智谱 / Qwen / Kimi / MiniMax 任选）
- [ ] 知道哪些任务首选国产（中文、便宜、批量），哪些任务首选国外（工具调用、超长上下文）
