## 任务 ↔ 推荐型号

| 任务类型 | 首选 | 备选 | 理由 |
| --- | --- | --- | --- |
| 中文问答、摘要 | DeepSeek-V3 | GLM-4.5 | 中文最强、最便宜 |
| 长论文阅读（>50K tok） | Sonnet 4.6 | Qwen3-Max | 上下文长 + 跨段落理解好 |
| Coding Agent / Claude Code | Sonnet 4.6 | GPT-4.1 | 工具调用最稳 |
| 推理 / 数学 / 思辨 | DeepSeek-R1 | GPT-5（高 reasoning） | 性价比 |
| 多模态（图像） | Gemini 2.5 Pro | GPT-4.1 | 原生多模态最成熟 |
| 大批量数据清洗 | DeepSeek-V3 | Haiku 4.5 | 单价低、并发好 |
| 写论文初稿（中文） | GLM-4.5 | DeepSeek-V3 | 中文笔触自然 |
| 写论文初稿（英文） | Sonnet 4.6 | GPT-4.1 | 学术英语稳定 |

## 选型口诀

> 便宜先试 V3 / GLM；复杂再上 Sonnet；推理瓶颈才用 R1 / GPT-5 高 reasoning。
