# 第 01 章 · 模型选型

> 对应 PPT 第 1–16 页

## WHAT —— 学什么

- **核心对象**：Token、Context、API、Reasoning、国产模型
- **真实场景**：在做一个新任务前，先决定用哪一个模型；不要默认 GPT-4 / Claude，也不要默认 DeepSeek
- **学习结果**：拿到一个新需求，能 10 分钟内做出"用哪家模型 + 用哪个具体型号 + 预估成本"的判断

## WHY —— 为什么学

- **痛点**：选错模型，后面的效率全都被打折——便宜的模型上下文太短装不下论文；推理模型贵 10 倍但简单问答用不上；国产模型对中文好但工具调用差
- **边界**：本章只解决"挑选 + 比较"，不解决"训练"和"微调"

## HOW —— 怎么做（4 步）

1. **按任务分型**：问答、长文、代码、写作、自动化——不同任务要的能力维度不同
2. **看约束**：上下文窗口够不够 / 是否要支持工具调用 / 预算上限 / 是否要中文输出
3. **建立小样本测试集**：用同一个任务测多个模型，记录结果
4. **整理成模板**：把验过的模型选型放进团队可复用的清单

## 怎么用

```powershell
cd 01-模型选型

# 方式 1：直接给一句话估算
python token估算.py "你好，请帮我把这段论文摘要翻译成英文，要求保留专业术语"

# 方式 2：用准备好的示例文本（三种不同形态）
python token估算.py --file 示例文本/中文摘要.txt           # 中文，498 字符 ≈ 505 token
python token估算.py --file 示例文本/英文段落.txt           # 英文，1033 字符 ≈ 193 token
python token估算.py --file 示例文本/长输入_论文章节.txt    # 中英混合，1820 字符 ≈ 1542 token
```

输出会告诉你这段文本大概多少 token，以及在 DeepSeek、GLM、Claude、GPT 上分别多少钱。

> **观察点**：中文每字 ≈ 1 token，英文每 5-6 字符 ≈ 1 token。同样字符数，中文比英文贵约 3-5 倍。这就是为什么"中文综述用国产模型 + 英文论文用 Claude"是一条值得记住的实战经验。

## 真要选模型，跑一遍小样本测试

光看价格表选不出最适合的——**用真实任务测**。

打开 [小样本测试_完整示例.md](./小样本测试_完整示例.md)，看一个填好的示例：「中文综述 → 英文标题 + 要点」，6 步 1.5 小时跑完，结论可直接落到团队 prompt 模板里。然后照 [小样本测试模板.md](./小样本测试模板.md) 填自己的任务。
