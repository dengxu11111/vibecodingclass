# 第 01 章 · 模型选型

> PPT 1–16

## 跑

```powershell
cd 01-模型选型
python token估算.py --file 示例文本/中文摘要.txt
```

498 字符中文 ≈ 505 token，9 家模型预估单价。

## 学完能

拿到新需求 10 分钟内判断：用哪家 / 哪个型号 / 多少钱。

## 怎么选

1. 任务分型：问答 / 长文 / 代码 / 写作 / 自动化
2. 看约束：上下文 / 工具调用 / 预算 / 中文
3. 跑小样本测试，记录结果
4. 沉淀到团队 prompt 模板

## 经验

中文 ≈ 1 字/token；英文 ≈ 5-6 字符/token。同字符数中文贵 3-5×。**中文综述用国产，英文论文用 Claude**。
