# 小样本测试模板

> 选模型不能只看跑分。**用你自己的真实任务**测一下，再做决定。

## 第 1 步：定义任务

写一句话讲清楚任务是什么、输入是什么、产出是什么、怎么算"做对了"。

```
任务名：______________________________
输入：______________________________
产出：______________________________
判定标准：（如：含参考文献 / 段落不超过 200 字 / 不能编造数据）
```

## 第 2 步：准备 3–5 条测试样本

样本要覆盖典型情况 + 边界情况：

| 编号 | 输入 | 期望产出（要点） |
| --- | --- | --- |
| s1 | …… | …… |
| s2 | ……（边界：超长输入） | …… |
| s3 | ……（边界：中英混合） | …… |
| s4 | ……（边界：含错别字） | …… |
| s5 | …… | …… |

## 第 3 步：选 3 个候选模型

挑一个国产便宜的、一个国产 / 国外强的、一个推理型，做三角对比。

```
候选 A：______（如 DeepSeek-V3）
候选 B：______（如 Claude Sonnet 4.6）
候选 C：______（如 DeepSeek-R1）
```

## 第 4 步：用同样的 prompt 跑一遍

**关键：prompt 完全一样，温度统一设为 0 或 0.2。**

| 样本 | 候选 A | 候选 B | 候选 C |
| --- | --- | --- | --- |
| s1 | …… | …… | …… |
| s2 | …… | …… | …… |
| s3 | …… | …… | …… |
| s4 | …… | …… | …… |
| s5 | …… | …… | …… |

## 第 5 步：按判定标准打分

|  | 候选 A | 候选 B | 候选 C |
| --- | --- | --- | --- |
| 准确率 | __ / 5 | __ / 5 | __ / 5 |
| 速度（s） | __ | __ | __ |
| 单条成本 ($) | __ | __ | __ |
| 是否中文自然 | __ | __ | __ |
| 总评 | __ | __ | __ |

## 第 6 步：结论沉淀

把"哪个任务用哪个模型"的判断写进团队 wiki / 本仓库的 `资源/常用prompt模板.md`，下次同类任务直接调用。

```
结论：任务【___】首选【___】，因为【便宜/上下文/中文/推理】。
备选：【___】，在【某场景】下切换。
```
