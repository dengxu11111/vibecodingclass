# 软件安装步骤

> 整理自《软件部署安装.docx》与《openclaw案例.pptx》，按 Windows 优先、Mac/Linux 兼顾。

## 0. 基础：网络与账号

课程主线走 **OpenClaw + DeepSeek**——国产 API、零账号风险、不需要科学上网。

- 到 <https://platform.deepseek.com/> 注册账号，拿一份 API Key（注册即送少量额度）
- 备选：<https://open.bigmodel.cn/>（智谱 GLM）或 <https://openrouter.ai/>（多家聚合）

> **API Key 安全**：拿到 Key 之后，**不要**贴进 README / 截图 / GitHub。配置成环境变量或 `.env`（被 .gitignore 忽略）。课程第 05 章会专门讲一遍。

> Claude Code / Codex 等海外工具需要稳定国际网络与官方账号——按所在地法规自行处理，本课程不展开。

## 1. Node.js

Codex / Claude Code 都通过 npm 安装，必须先装 Node.js。

下载：<https://nodejs.org/en/download>（选 LTS 版，推荐 Chocolatey 安装器，一路点下一步即可）

验证：

```powershell
node --version
npm --version
```

## 2. Claude Code

```powershell
npm install -g @anthropic-ai/claude-code
claude --version
```

首次运行会引导登录 Anthropic 账号或粘贴 API Key。

## 3. Codex（OpenAI 官方 Agent CLI）

```powershell
npm install -g @openai/codex
codex --version
```

首次运行 `codex` 会让你登录 ChatGPT 账号。零基础同学如果暂时没有 ChatGPT Plus / Pro，可以直接跳到 OpenClaw + DeepSeek 那条路径——课程的实操绝大部分都不依赖 codex CLI 本身。

## 4. OpenClaw

OpenClaw 是国产的 Claude Code 兼容前端，可以接 DeepSeek、智谱 GLM、OpenRouter 等国产 / 聚合模型。

1. 官网下载安装包：<https://openclaw.ai/>
2. 安装后第一次启动会提示配置 API Key
3. 推荐先配 **DeepSeek**：到 <https://platform.deepseek.com/api_keys> 申请 key，复制到 OpenClaw 的配置面板
4. 没有 DeepSeek key 也可以试 **OpenRouter** 的免费大模型：<https://openrouter.ai/keys>

详细截图与配置流程见 PPT《openclaw案例.pptx》。

## 5. Ollama（本地大模型）

下载：<https://ollama.com/download>

```powershell
# 装好后拉一个小模型试试（约 2.5 GB，看网速一般 3-10 分钟）
ollama pull qwen3.5:4b
ollama run qwen3.5:4b "你好，简单介绍下你自己"
```

> 4B 模型对显卡 / 内存友好（8 GB 内存的笔记本就能跑）；想要更强可以拉 `qwen3.5:8b` 或 `qwen3.5:30b-a3b`，配置见各模型在 <https://ollama.com/library> 的标签页。

Ollama 默认监听 `http://localhost:11434`，第 02 章会用到。

## 6. Docker Desktop

下载：<https://www.docker.com/products/docker-desktop/>

装完后**重启电脑**，打开 Docker Desktop，等鲸鱼图标变绿。

验证：

```powershell
docker --version
docker ps
```

## 7. Python 与第三方包

```powershell
python --version            # 需要 3.10+
pip install requests pandas matplotlib tiktoken jupyter mcp
```

国内 pip 慢，可以加镜像：

```powershell
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple requests pandas matplotlib tiktoken jupyter mcp
```

## 8. 编辑器 / IDE

推荐 **VS Code**：<https://code.visualstudio.com/>

装好后建议装两个插件：

- **Claude Code**（来自 Anthropic 官方）
- **Codex**（来自 OpenAI 官方）

按红框图标进 Extensions 搜索就能找到。

## 装完检查

回到 [README.md 的"验收"](./README.md#验收) 跑一遍版本号命令。
