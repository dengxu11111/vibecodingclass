# 常见问题

## Q1：`npm install -g` 卡住或报权限错误

- Windows：以管理员身份打开 PowerShell 再试
- 国内网络慢可以切镜像：`npm config set registry https://registry.npmmirror.com`

## Q2：`claude` / `codex` 装好后命令找不到

- 通常是 npm 的全局目录没加到 PATH。运行 `npm config get prefix` 拿到路径，把其下的 `bin`（或 Windows 的根目录）加到环境变量 PATH。

## Q3：Claude Code 一启动就报 "Anthropic API error"

- 检查是不是网络问题：能不能访问 <https://www.anthropic.com>
- 检查账号或 API Key 是否过期 / 额度耗尽
- 国内同学最稳妥的路径是用 **OpenClaw + DeepSeek** 替代

## Q4：Docker Desktop 启动报 WSL 错误

- Windows 10/11 需要先启用 WSL2：以管理员身份运行 `wsl --install`，然后重启
- 企业电脑可能禁了虚拟化，需要 BIOS 里打开 VT-x / SVM

## Q5：Ollama 下载模型奇慢

- 试试国内代理 / 切换网络
- 或者用更小的模型先跑通：`ollama pull qwen3.5:0.6b`

## Q6：`docker compose up` 报 "no space left on device"

- Docker 默认占 C 盘很大，Settings → Resources → Advanced 调小磁盘镜像，或者迁移到 D 盘

## Q7：OpenClaw 提示 API Key 无效

- 检查复制时有没有带上首尾空格
- DeepSeek key 必须以 `sk-` 开头
- 余额耗尽也会报同样错误，到 <https://platform.deepseek.com/usage> 查一下

## Q8：路径里有中文 / 破折号怎么办

如果你 clone 后的本地路径含中文、空格、或破折号（例如 `D:\课程\vibe—coding`），在 PowerShell / cmd 里用绝对路径时一律用引号包起来：

```powershell
cd '<你的本地仓库路径>'   # 例：'D:\repos\vibecodingclass' 或 'D:\课程\vibe—coding'
```

VS Code 里 `code .` 打开当前目录最省事。

## Q9：跑 Python 脚本报 `ModuleNotFoundError`

```powershell
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <缺的包名>
```

只看 Markdown 也能学：每一章 README 都把 WHAT / WHY / HOW 写完整，代码也直接贴在文件里看得懂。后面有条件再补环境。
