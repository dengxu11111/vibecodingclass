# 04 · 起草（多模型协作 · 跨领域模板）

> 不写脚本，在 Claude Code / OpenClaw 对话里跑。三角色：资料员 → 起草员 → 审稿员。
> 五角色完整版（加批判员 + 润色员）见 [../09-论文自动化/多模型角色分工.md](../09-论文自动化/多模型角色分工.md)。

## 强约束：数字回链

每个进稿子的数字都必须能在 `data/processed/<domain>_*.csv` 里找到。两种实现，二选一或都用：

1. **CLI 兜底**：写完后跑 `python ../capstone-科研数据分析/05_核验.py outputs/起草员_v1.md`
2. **MCP 强约束**：把第 07 章的 `vibecoding-capstone` MCP 改成你领域版，Agent 写每个数字前先 `verify_number(...)`

## 1. 资料员（DeepSeek-V3 / GLM-4.5）

```
你是【资料员】。

读 data/processed/<domain>_summary.csv 和 data/processed/<domain>_clean.csv。
（配了 MCP 就先调 load_summary()，别 read_file 边读边写）

输出 Markdown 表格：
| <你的分组维度> | n | mean | sd | <你领域关键统计> | 备注 |

规则：
- 数字只能照搬 csv，不允许补完
- 不确定字段填 [待人工核验]
- 排序按 <你领域有意义的维度>
- 最后写 3 条「能不能下结论」的限制（样本 / 测量假设 / 代表性）

保存到 outputs/资料员_主题表.md
```

## 2. 起草员（Claude Sonnet 4.6 / GLM-4.5）

```
你是【起草员】。

读 outputs/资料员_主题表.md 和 outputs/ 下的 PNG。
配了 MCP：**每个数字** 出现前先 verify_number("<num>")，找不到的不许写。

写一篇 600-1000 字 mini 综述，回答：「<你的研究问题，一句话>」

结构：
1. 数据与方法（80-120 字）：源 / 时间窗 / 采样 / 统计方法
2. 主要发现（200-300 字）：按有意义的排序列前 3，带数字 + 不确定性
3. 区域 / 子群对比（150-200 字）：照搬资料员表分类，**不许**自创标签
4. 局限与展望（100-150 字）：方法假设、样本边界、未来方向

规则：
- 每个数字来自 csv 或图，不许编造
- **禁用词**：显著 / 大幅 / 明显 / 确凿 / 毫无疑问
  → 替换：差异方向一致 / 幅度较大 / CI 不含 0 / p<0.05 / 效应量 d=...
- 不许引入超出样本能支撑的因果解释
- 平实学术中文，每句 ≤ 40 字
- 引用图："（见图 1 / outputs/<domain>_main.png）"

保存到 outputs/起草员_v1.md
```

## 3. 审稿员（Sonnet 4.6 / DeepSeek-R1）

```
你是【审稿员】。

读 outputs/起草员_v1.md + outputs/资料员_主题表.md。
对起草员 v1 里**每一个数字**调 verify_number() 或人工 grep csv，
found=false 的列进「编造数字」节。

输出一份 outputs/草稿_v2.md，分两部分：

## 上半部分：审稿报告

按 4 类问题：
1. 编造数字：[行号 / 原文 / 反证 / 建议]
2. 禁用词：列原文 + 替换建议
3. 超出样本的解释：你领域典型"过度归因"
4. 自造分类：标签是不是来自资料员表

打分表 + 总评（通过 / 待修改 / 拒绝）。

## 下半部分：v2 正文

按审稿意见改 v1，每句 ≤ 40 字。末尾「修改记录」。
```

## 4. 研究者（你）

## 跨领域调整建议

| 领域 | 起草员第 2 节强调 | 审稿员重点抓 |
| --- | --- | --- |
| 气候 / 遥感 | slope ± CI、Sen vs OLS、MK p | 自相关未校正、单像元不代表区域 |
| 文献计量 | 频次、增长率、Top-N | "热度增长" ≠ "重要性增长"、抽样窗口偏差 |
| 生信 | log fold change、adj p、效应量 | 多重检验校正、batch effect、样本量 |
| 临床 / 流行病 | HR / OR + 95% CI、p | 失访、选择偏倚、未控混杂 |
| 经济 / 金融 | β、t 统计、R²、残差 | 平稳性、内生性、抽样窗口 |
| 社科 / 调查 | 均值差 + 效应量、卡方 | 应答偏倚、问卷措辞、随机化失败 |
| 化学 / 材料 | RMSE、ROC AUC、跨集泛化 | 训练集污染、特征工程偏倚 |

## 啥时候三角色不够

- 真投期刊 → 切第 09 章五角色版
- 多数据源 / 多方法对比 → 起草员阶段拆"data 子员"
- 争议性结论 → 审稿员拆出独立"批判员"
- 跨语言投稿 → 加"润色员"
