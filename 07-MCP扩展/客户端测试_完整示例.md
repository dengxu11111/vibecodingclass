# MCP 客户端测试 · 完整示例

> `最小MCP-server.py` 启动后"挂住"等 client，**正常现象**。这份文档用真实 JSON 讲清楚 4 个 tool 长什么样。

## 4 个 MCP tool 速查

| Tool | 输入 | 返回 |
| --- | --- | --- |
| `load_annual(city)` | `city: str` | `{"city", "years", "temps_c", "n", "source"}` |
| `compute_ols_trend(years, values)` | 两个数列 | `{"n", "slope", "intercept", "ci95_low", "ci95_high", "r2", "se_slope"}` |
| `load_trend_summary()` | 无 | `{"rows": [{每城 OLS+MK+Sen}], "source"}` |
| `verify_number(value, file?, tol?, column?, city?)` | `value: str` | `{"found", "match_count", "hits", "available_columns", "available_cities", ...}` |

## 用 MCP Inspector 单测（不用 Claude Code）

```powershell
npm install -g @modelcontextprotocol/inspector
npx @modelcontextprotocol/inspector python 07-MCP扩展/最小MCP-server.py
```

浏览器自动开 `http://localhost:5173`，左边面板有 4 个 tool。

## 真实输出样例

### `load_annual("北京")`

server 实际读 `capstone-科研数据分析/data/processed/era5_annual.csv`（Open-Meteo 主线产物，30 年）：

```json
{
  "city": "北京",
  "n": 30,
  "years": [1995, 1996, 1997, ..., 2024],
  "temps_c": [12.10, 11.62, 12.71, ..., 13.84],
  "source": "capstone-科研数据分析/data/processed/era5_annual.csv"
}
```

> CDS 路径产物 `era5_cds_annual.csv` 当前 MCP server **不读**——如果你只跑了 CDS 路径，先把 `era5_cds_annual.csv` 改名 / 复制成 `era5_annual.csv`，或扩展 server 支持双 schema。

### `compute_ols_trend(years, values)`（用上面的 30 年数据）

```json
{
  "n": 30,
  "slope": 0.0258,
  "intercept": -39.045,
  "ci95_low": 0.0052,
  "ci95_high": 0.0464,
  "r2": 0.190,
  "se_slope": 0.0101,
  "t_crit_95": 2.048
}
```

n=30 时 CI 不含 0，OLS 与 capstone `02_分析.py` 输出对得上（slope=0.0258，CI [0.0052, 0.0464]）。

### `verify_number(value="0.0258")`

```json
{
  "found": true,
  "match_count": 10,
  "hits": [
    {"city": "北京", "column": "ols_slope_c_per_year", "csv_value": 0.0258, "diff": 0.0},
    {"city": "北京", "column": "mk_p", "csv_value": 0.0295, "diff": 0.0037}
  ],
  "file": "capstone-科研数据分析/data/processed/趋势汇总.csv",
  "available_columns": ["city", "years", "n", "mean_temp_c",
                        "ols_slope_c_per_year", "ols_ci95_low", "ols_ci95_high", "r2",
                        "mk_S", "mk_Z", "mk_p", "mk_trend",
                        "sen_slope_c_per_year", "sen_ci95_low", "sen_ci95_high"],
  "available_cities": ["上海","乌鲁木齐","北京","哈尔滨","广州","武汉","西安"]
}
```

加 `column` + `city` 收窄到精确字段；仓库没有的数 `value="0.999"` → `{"found": false}`。

注意：`verify_number` 是**数值容差匹配**，不是子串。`value="0.45"` **不会**假命中 `0.4519`（diff=0.0019 > tol=0.01）。

## 接到 Claude Code

合并 `mcp配置样例.json` 的 `vibecoding-capstone` 到 `~/.claude.json`，重启。对话框：

```
用 vibecoding-capstone 的 load_trend_summary，把 7 城趋势按 slope 降序输出 Markdown 表。
```

**vs 无 MCP**：无 MCP 时 Claude Code 自己 `read_file` 读 csv，可能解析错；有 MCP 时数据从 Python 端结构化返回，**Claude Code 只负责呈现**。

## 常见疑问

| 现象 | 解释 |
| --- | --- |
| 跑了没输出就卡住 | **正常**，stdio 等 client。**不要 Ctrl+C**，用 inspector 或 Claude Code 连进去就活 |
| Inspector 网页打不开 | `npm install -g` 成功？公司网可能拦 5173 |
| Claude Code 看不到 vibecoding-capstone | `~/.claude.json` 里 `command` 是绝对路径吗？ |
| `load_annual` 返回 `error` | 还没跑 capstone 02_分析.py |
