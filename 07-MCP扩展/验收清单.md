# 第 07 章 · 验收清单

> 对应 PPT 第 77 页 SUMMARY。

## 协议层（必须）

- [ ] 能解释 Tool、Resource、Prompt 在 MCP 中各自适合什么
- [ ] 能写出一个工具的输入、输出、权限和失败条件
- [ ] 能说明为什么写入类工具必须增加确认和日志

## 跑通本仓库的 capstone MCP server

- [ ] `pip install mcp` 没报错
- [ ] `python 07-MCP扩展/最小MCP-server.py` 能挂起来不退出
- [ ] 用 `npx @modelcontextprotocol/inspector python 07-MCP扩展/最小MCP-server.py` 在网页里能看到 4 个 tool
- [ ] `load_annual({"city": "北京"})` 真的返回了一串年度温度（不是 error）
- [ ] `compute_ols_trend(years, values)` 算出来的 slope 和 capstone `02_分析.py` 输出**对得上**
- [ ] `verify_number("0.0258")` 能回 grep 到北京那一行（30 年版的 OLS slope；5 年版用 `"0.4519"`）
- [ ] `verify_number("9.9999")` 返回 `found=false`——证明工具确实在查 csv，不是瞎编
- [ ] `verify_number("0.45")` 返回 `found=false`——证明用的是**数值容差**而非子串（旧版会假命中 0.4519）
