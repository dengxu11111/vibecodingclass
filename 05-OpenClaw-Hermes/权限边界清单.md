# 权限边界清单

> 给 OpenClaw / Hermes 第一次跑任务的同学：先把权限定窄，再逐步放开。

## 路径白名单

只允许 Agent 在下面的目录里读写：

```
<repo-root>\          # 本仓库
<repo-root>\outputs\  # 它自己的输出区
<repo-root>\data\     # 数据缓存
```

**禁止**：
- 桌面、文档、下载等用户目录
- C 盘系统目录
- 任何 `.git` 目录

## 工具白名单

| 工具 | 允许 | 说明 |
| --- | --- | --- |
| `read_file` | ✓ | 读任何在白名单路径下的文件 |
| `write_file` | ✓ | 只能写到 `outputs/` 和 `data/` |
| `run_shell` | 看情况 | 允许 `python`、`git status`、`git diff`；禁止 `rm`、`del`、`format` |
| `web_search` | ✓ | 只读、限速 |
| `web_fetch` | ✓ | 只读公开 URL |
| `git_commit` | ✗ | 课堂环境不让自动 commit |
| `git_push` | ✗ | 永远不让 |

## 模型与 Token 上限

- 单次调用最大 token：8K（输入）+ 4K（输出）
- 单任务最大轮数：10 轮（防止 Agent 卡循环）
- 每天预算：5 元 / 学生

## 触发"必须确认"的操作

- 删除任何文件
- 写入超过 10 MB 的文件
- 安装新的 pip / npm 包
- 调用计费 API（非免费的网络抓取、付费数据集）

## 配置示例（OpenClaw 风格）

OpenClaw 一般在 设置 → 安全 / 权限 里设。下面是配置心理模型：

```yaml
allowed_paths:
  - <repo-root>\
denied_paths:
  - .git
  - $env:USERPROFILE\Desktop
  - $env:USERPROFILE\Documents
tool_policy:
  read_file: allow
  write_file: ask_outside([outputs, data])
  run_shell:
    allow: [python, git status, git diff]
    deny:  [rm, del, format, shutdown]
  git_commit: deny
budget:
  max_tokens_per_call: 12000
  max_turns_per_task: 10
  max_yuan_per_day: 5
```
