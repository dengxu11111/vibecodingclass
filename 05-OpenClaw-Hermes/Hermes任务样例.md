# Hermes / OpenClaw 任务样例

> 三个真实可跑的小任务，让你第一次感受"Agent 操作你的本地项目"是什么体验。
> 都在本仓库目录下做，跑完不会乱动你的其他文件。

## 任务 1：让 Agent 读 README 然后写一份导读

**前置**：用 OpenClaw 打开本仓库目录（`<repo-root>`）。

**对 Agent 说**：

```
请阅读本仓库的 README.md 和 00-课前准备/README.md，
然后在 outputs/ 目录下生成一份 课程导读.md，
要求：用大学生能看懂的语言、不超过 300 字、列出 5 个最关键的章节。
```

**预期**：
- Agent 会先调用 `read_file` 工具
- 然后写出 `outputs/课程导读.md`
- 让你确认是否覆盖 / 创建文件

**学到什么**：Agent = LLM + 工具调用（Tool Use）。文件读写是工具，不是 LLM 自带能力。

## 任务 2：让 Agent 抓 arXiv 数据并出图

**对 Agent 说**：

```
帮我做一件事：
1. 用 Python 抓 arXiv 上「quantum machine learning」最近 100 篇论文的标题和日期
2. 把数据存到 outputs/qml.csv
3. 画一张按月发文量的柱状图保存到 outputs/qml.png
4. 跑完告诉我中位月份和峰值月份
```

**预期**：
- Agent 写 `outputs/抓arxiv.py`，跑一次
- 看到 csv 和 png 都生成
- 终端打印分析结论

**学到什么**：Agent 不止能写代码，还能跑代码、看结果、再返回结论。

## 任务 3：让 Agent 整理一份周报

**对 Agent 说**：

```
我这周的工作记录在 03-Vibe-Coding/调试记录模板.md（先帮我填一份示例），
请基于它生成一份给团队 / PI / 导师看的周报：
- Markdown 格式
- 5 段：本周工作 / 关键发现 / 下周计划 / 风险 / 求建议
- 不要编造数据，没数据的地方留 [待填]
```

**预期**：Agent 会先调 `write_file` 把模板填几条示例数据，然后调 `read_file` 读回来，再写出周报。

**学到什么**：

- 多步任务里，Agent 自己管"先做什么、后做什么"
- 你只需要写"做什么"和"什么不能做"（不要编造数据）

## 一次跑码 Agent 演示流程

把上面三个任务连在一起，就是 PPT 第 49 / 53 页提到的"一次跑码 Agent 演示流程"：

```
1. 配 API Key + 项目路径
2. 任务 1 验证文件读写
3. 任务 2 验证代码生成 + 执行
4. 任务 3 验证多步推理 + 模板复用
```

跑完恭喜你——你已经走完了 Agent 的"端到端最小闭环"。
