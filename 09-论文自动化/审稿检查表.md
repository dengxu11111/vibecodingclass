# 审稿检查表

> 这是审稿员 / 批判员 / 自查时通用的清单。能勾全就交稿。

## 一、证据链

- [ ] 每一处事实陈述都标了来源（论文 id / 数据文件行号 / 实验脚本）
- [ ] 引用的论文确实在自己的数据集里（不是 LLM 编的）
- [ ] 数字 / 百分比都能在原始数据里查到
- [ ] 图表的数据源在脚注或附录写清楚了

## 二、逻辑

- [ ] 每一段都能用一句话总结主旨
- [ ] 没有"显著提升"、"大幅改善"、"大多数"这类没数据支撑的口语
- [ ] 段落之间有清晰的承接（不是把 ChatGPT 拼接的列表直接贴上来）
- [ ] 反例 / 限制 / 边界条件至少写了一段

## 三、引用

- [ ] 每个 `(arxiv_id)` 或 `[N]` 都能在参考文献列表找到
- [ ] 参考文献的标题、作者、年份和 arXiv 上一致
- [ ] 没有出现"作者通讯"或"私人沟通"这种不可验证的引用

## 四、风格

- [ ] 通篇风格统一（不是多个模型生成段落直接拼）
- [ ] 标题 / 图表 / 公式编号连贯
- [ ] 中文学术语言：每句不超过 40 字、被动句不堆砌
- [ ] 英文学术语言：现在时为主、避免缩写、第三人称

## 五、合规

- [ ] 不包含未公开的实验数据 / 未授权的内部资料
- [ ] 用了 AI 辅助有明确标注（致谢部分或方法部分）
- [ ] 数据来源、API 版本、模型版本、日期都有记录

## 总评

- [ ] **通过**（可以投稿 / 提交）
- [ ] **待修改**（列出 3 件必须改的事）
- [ ] **拒绝**（说明根本性问题）
