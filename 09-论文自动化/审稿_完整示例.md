# 审稿 · 完整示例

> [审稿检查表.md](./审稿检查表.md) 填完之后长这样。被审稿件是一份**故意藏错**的草稿（基于 example/capstone_5y_cds，埋了 6 类典型 LLM 病）。

## 被审稿件（节选）

```
## 主要发现

1995-2024 年中国 7 座代表性城市的年均 2 m 气温**均显著升高**，幅度在 +0.024 至 +0.061 °C/年之间。
其中西安升幅最大（slope = +0.0612 °C/年，95% CI [+0.045, +0.077]），其次为北京（+0.0567）。
**东部沿海三城**升幅明显高于内陆，可能与城市热岛及东亚季风减弱有关。
广州 2024 年均温 24.3 °C，达 30 年最高，与 ENSO 暖位相一致。

参考文献：
[1] IPCC AR6 WG1 (2021)
[2] Hersbach et al. (2020) ERA5 reanalysis
[3] 张, 王, 李 (2023). 中国城市热岛效应综述. (通讯私下提供)
```

## 审稿员对每一类的回应

### 一、证据链

| 检查项 | 通过 / 不通过 | 证据 |
| --- | --- | --- |
| 事实标来源 | ❌ | "西安升幅最大" 没引 csv 行号；"东部沿海三城" 无支撑 |
| 引用真存在 | ⚠ | [3] **疑似 LLM 编造**——"通讯私下提供"不可验证 |
| 数字可查 | ❌ | "广州 2024 年均温 24.3 °C" 查 csv 第 13 行实际 **23.610 °C**，编了 0.7 |

### 二、逻辑

| 检查项 | 通过 / 不通过 | 证据 |
| --- | --- | --- |
| 无"显著""大幅"等无据程度词 | ❌ | "**均显著升高**" + "升幅**明显**高于" |
| 反例 / 限制 | ❌ | 整段没局限——单像元 / 自相关 / 7 城代表性 / ENSO 解释超出样本，全没写 |

### 三、引用

| 检查项 | 通过 / 不通过 | 证据 |
| --- | --- | --- |
| 无"私人沟通"类不可验证引用 | ❌ | [3] 必删 |

### 四、合规

| 检查项 | 通过 / 不通过 | 证据 |
| --- | --- | --- |
| AI 使用声明 | ❌ | **没说哪部分是 AI 生成** |
| 数据 manifest | ⚠ | 只说"ERA5"，没记 CDS dataset name / 请求日期 |

## 总评：待修改（major revision）

6 处硬伤要改完再二审：

1. 删 **"显著"** 三处 → "CI 不含 0"或"升幅 +X °C/年"
2. 删 **"东部沿海三城"** 自造分类 → 必须照搬资料员表里的归类
3. 改错数字 **"广州 2024 年均温 24.3 °C"** → **23.610 °C**
4. 删 **[3] 通讯引用** → 整条删，或换可查文献
5. 删 **ENSO 解释** → 30 年单像元 OLS 不支撑因果归因
6. 补 **AI 使用声明 + 数据 manifest**

修完跑 `python capstone-科研数据分析/05_核验.py outputs/最终稿.md` → untraced=0。

## 关键观察：6 类病对应 6 条 prompt 约束

| 病症 | 出处 | 防御办法 |
| --- | --- | --- |
| 数字编造 | "广州 24.3 °C" | 起草员 prompt 强制"每个数字 grep csv" + 跑 `05_核验.py` |
| 程度词无据 | "显著升高" | 起草员 prompt 列禁用词 |
| 自造分类 | "东部沿海三城" | 起草员 prompt 强制"分类必须来自资料员表" |
| 超出样本解释 | ENSO 归因 | 禁止引入 csv 无支撑的物理解释 |
| 编造引用 | [3] 通讯 | 强制"只引可查文献" + 审稿员核引 |
| 缺合规标注 | 无 AI 声明 | 研究者（人）补，不让 AI 写自己的免责声明 |

每类对应 capstone `04_起草.md` 三角色 prompt 的一条硬约束。**草稿出现哪类病，回去修 prompt 比改稿子更划算**。
