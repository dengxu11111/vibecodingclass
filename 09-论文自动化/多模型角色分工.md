# 多模型角色分工

> PPT 第 92 页讲：让不同的模型扮演不同角色，最后由研究者统一。
> 这一份文件给你一份**可直接复制的 prompt 包**。

## 五个角色 + 对应的 Skill

每个角色优先 **`Use the <skill> skill`** 触发对应的 vendor 自 K-Dense 的生产级 Skill（见第 06 章 [`CREDITS.md`](../06-Skill封装/.claude/skills/CREDITS.md)）；没有对应 Skill 的角色就用通用 prompt。

| 角色 | 推荐模型 | 对应 Skill | 任务 | 关键约束 |
| --- | --- | --- | --- | --- |
| **资料员**（Data） | DeepSeek-V3 / GLM-4.5 | `literature-review` | 把抓到的论文 / 数据整理成结构化表格 | **不允许编造**，缺数据就标 `[待填]` |
| **起草员**（Draft） | Claude Sonnet 4.6 / GLM-4.5 | `scientific-writing` | 写论文 / 综述初稿 | 每一段必须**带证据来源**（论文 id 或数据行号） |
| **审稿员**（Reviewer） | DeepSeek-V3 / Claude Sonnet 4.6 | `peer-review` | 按审稿表逐项检查 | 输出"通过 / 待修改 / 拒绝" + 理由 |
| **批判员**（Critic） | DeepSeek-R1 / Claude Opus 4.7 | `scientific-critical-thinking` | 专挑证据不足、逻辑跳跃 | 至少指出 3 处问题，每处给出反例 |
| **润色员**（Polish） | Claude Sonnet 4.6 / GPT-4.1 | （无 — 通用 prompt） | 学术英语 / 学术中文风格修整 | **不改观点**，只改语言 |

最后**研究者**自己统一所有修改，拍板交稿。

> 上面 4 个英文 Skill 已 vendor 在 `.claude/skills/` 下，clone 仓库后 Claude Code 自动识别。改提示词时只需要在开头加一句 `Use the <skill-name> skill.`，Skill 自带的工作流程会接管后面的步骤。

## Prompt 包

### 角色 1：资料员

```
你是【资料员】。

输入：data/processed/arxiv_xxx_clean.csv（{N} 篇论文）。

任务：把这些论文按主题分组，输出一张 Markdown 表格：
| 论文 ID | 标题 | 主题 | 方法 | 关键结论 |

规则：
- 字段只能来自 csv 里的真实内容，不允许补完
- 不确定的字段填 [待人工核验]
- 主题归类必须能在表后一句话解释
```

### 角色 2：起草员

```
你是【起草员】。

输入：上一步资料员输出的表格。

任务：写一段 300 字的研究综述，回答：「过去 5 年 large language model 研究的 3 个主要方向是什么？」

规则：
- 每个主张都必须 **(arxiv_id)** 括号引用至少一篇论文
- 不许出现表格里没有的论文
- 用学术中文，平实克制
```

### 角色 3：审稿员

```
你是【审稿员】，按下面这张表逐项打分：

[贴上 审稿检查表.md 的全部内容]

输出格式：
| 检查项 | 是否通过 | 证据 / 问题 |

最后给出总评：通过 / 待修改 / 拒绝，附 100 字理由。
```

### 角色 4：批判员

```
你是【批判员】。

输入：起草员的 300 字综述 + 资料员的表格。

任务：找出至少 3 个问题：
1. 有没有引用了表格里不存在的论文？
2. 有没有把"大多数"、"显著提升"这种话写得没有数据支撑？
3. 有没有逻辑跳跃（A→C，但中间 B 没说清楚）？

每个问题给出反例（具体引用哪一段、哪一句）。
```

### 角色 5：润色员

```
你是【润色员】。

任务：把综述改成更顺的中文学术语言，要求：
- 不动事实和引用
- 不删段落
- 把口语化的表达改成书面
- 控制每句话不超过 40 字

输出：润色后的版本 + 「修改了什么」的 diff 列表。
```

## 一次完整跑通的流程

1. 跑 `08-数据工作流/下载脚本.py` 抓数据
2. 跑 `08-数据工作流/数据清洗.py` 整理
3. 资料员 → 起草员 → 审稿员 → 批判员 → 润色员 → 研究者拍板
4. 跑 [审稿检查表.md](./审稿检查表.md) 最终核验
5. 出稿

详细在 [capstone-科研数据分析/](../capstone-科研数据分析/) 有完整可跑示例。
