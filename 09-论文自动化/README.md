# 第 09 章 · 论文自动化

> 对应 PPT 第 86–96 页

## 学完这章你能

**让 5 个不同模型扮演资料员 / 起草员 / 审稿员 / 批判员 / 润色员**，把一份数据集变成可投稿的综述初稿——**每个数字都能回链 csv，没有 LLM 编的数据**。

## 5 分钟先看这个

```powershell
code 09-论文自动化/审稿_完整示例.md
```

一份**故意藏 6 类典型 LLM 病**的草稿（编造数字 / "显著"无据 / ENSO 超解释 / 自造分类 / 编引用 / 缺合规标注），按 5 维度逐项审稿打分。看完你会**反推**起草员 prompt 应该写哪些硬约束。

## WHAT —— 学什么

- **核心对象**：Evidence Chain、Reviewer、Critic、文献摘要、引用核验
- **真实场景**：用多个模型辅助读论文、整理证据、生成综述草稿，但把引用和结论牢牢掌握在人手里
- **学习结果**：能搭建一条“检索 → 摘要 → 对比 → 质疑 → 改写 → 核验”的论文工作流

## WHY —— 为什么学

- **痛点**：LLM 很擅长写顺滑文字，但也很容易把不存在的引用写得像真的
- **边界**：本章不教“自动写论文”，而是教如何把 AI 放进可审计的科研辅助流程

## HOW —— 怎么做（5 步）

1. 固定论文来源和筛选标准
2. 逐篇提取问题、方法、数据、结论和限制
3. 用对比表找共性、分歧和空白
4. 让 Critic 模型专门挑证据不足和逻辑跳跃
5. 人工核验引用、数字和关键结论

## 怎么用

1. 先用第 08 章或 capstone 生成结构化数据和图表。
2. 按 [多模型角色分工.md](./多模型角色分工.md) 依次跑资料员、起草员、审稿员、批判员、润色员。
3. 用 [审稿检查表.md](./审稿检查表.md) 做最终核验。
4. 研究者人工确认每个数字、引用和结论。
