# 第 09 章 · 论文自动化

> PPT 86–96

## 读

```powershell
code 09-论文自动化/审稿_完整示例.md
```

一份**故意藏 6 类典型 LLM 病**的草稿（编数 / "显著"无据 / 超解释 / 自造分类 / 编引用 / 缺合规），5 维度审稿打分。看完反推起草员 prompt 要写哪些硬约束。

## 学完能

搭"检索 → 摘要 → 对比 → 质疑 → 改写 → 核验"的论文工作流，引用和结论始终在人手里。

## 怎么做

1. 固定来源 + 筛选标准
2. 逐篇提取：问题 / 方法 / 数据 / 结论 / 限制
3. 对比表找共性 / 分歧 / 空白
4. Critic 模型挑证据不足
5. 人工核验引用 / 数字

## 底线

不是"AI 自动写论文"。把 AI 放进可审计的科研辅助流程。
