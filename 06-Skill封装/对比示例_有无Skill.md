# 对比示例 · 有 Skill vs 无 Skill

> 同一个数据清洗任务 A/B 跑两次，看 Skill 到底有用没有。

## 任务

```
读 capstone-科研数据分析/data/raw/era5_all.csv（7 城日均，12782 行），帮我：
1. 去重（city + date 复合键）
2. 日期格式统一 YYYY-MM-DD
3. temp_c 异常值（< -50 或 > 50）**标记 NaN 但保留行**
4. 输出到 data/processed/era5_cleaned.csv
5. 给清洗动作 + 数据质量摘要
```

## A. 无 Skill（裸 prompt）

| 评估项 | 结果 |
| --- | --- |
| 原始文件只读 | ❌ 直接 read 后 to_csv 覆盖（虽换目录但无明确意图） |
| 日期统一 | ✅ |
| 异常值标 NaN | ⚠ **删行**了，少 12 行 |
| 输出路径 | ✅ |
| 摘要质量 | ⚠ 只给"删了多少行"，没说哪列、什么范围、行数前后 |
| 迭代轮数 | 1-2 轮（学员发现异常值被删后要求改） |

## B. 启用 Skill（prompt 第一行加 `Use the 数据清洗 skill.`）

同一个学员、同一个模型、同一段任务：

| 评估项 | 结果 |
| --- | --- |
| 原始文件只读 | ✅ Skill 规则 |
| 日期统一 ISO | ✅ Skill 默认 |
| 异常值标 NaN 保留行 | ✅ Skill 硬约束"不擅自删除" |
| 输出路径 | ✅ |
| 摘要质量 | ✅ 6 条数据质量观察 |
| 迭代轮数 | 一次成功 |

## 差异在哪

两段 prompt 完全一样，唯一差别是 B 第一行 `Use the 数据清洗 skill.`。

打开 [.claude/skills/数据清洗/SKILL.md](../.claude/skills/数据清洗/SKILL.md) 看「默认规则」段——3 条规则没在裸 prompt 里说，但学员的预期就是这样。

**Skill = 团队共识 + 默认规则 + 验收标准** 三件套，绑到一个触发器。
省 token、省时间、产物形态强一致（甲乙丙不会出三种风格的清洗）。

## 什么时候**不**值得封 Skill

- 任务只做一次（过度工程）
- 团队只有你一个人且记性好
- 任务规则经常变（Skill 反成枷锁）

**经验**：同一个规则你或同事重复说过 3 次 → 封 Skill。
