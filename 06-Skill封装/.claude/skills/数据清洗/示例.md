# 数据清洗 Skill · 调用示例

## 示例 1：清洗 arXiv 抓回来的 CSV

**用户对 Claude Code 说**：

```
用「数据清洗」Skill 把 data/arxiv_raw.csv 清洗一下，
主键是 arxiv_id，时间列是 published_date，把列名都改成 snake_case。
```

**Skill 自动执行**：

1. 读 `data/arxiv_raw.csv`，输出原始统计（行数、列数、字段名）
2. 列名规范化：`Arxiv ID` → `arxiv_id`，`Paper Title` → `paper_title`
3. 按 `arxiv_id` 去重，告诉用户删了多少重复
4. 把 `published_date` 转 `datetime` 并升序排
5. 保存到 `data/arxiv_raw_clean.csv`
6. 打印 Markdown 数据质量报告

**预期输出**：

```markdown
## 清洗报告

| 项 | 原始 | 清洗后 |
| --- | --- | --- |
| 行数 | 217 | 198 |
| 重复行 | —— | 19 |
| 关键列缺失 | —— | 0 |

### 数据质量观察
1. `category` 列有 12 个不同值，集中在 cs.CL、cs.AI、cs.LG
2. 7 篇论文标题含 LaTeX 公式标记 $...$，下游使用前需要清理
3. 5% 的 abstract 长度 < 100 字符，可能是抓取截断
```
