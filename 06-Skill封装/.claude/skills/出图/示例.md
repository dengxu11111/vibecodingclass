# 出图 Skill · 调用示例

## 示例 1：按月发文量趋势图

**用户对 Claude Code 说**：

```
用「出图」Skill 给 data/arxiv_clean.csv 画一张按月发文量柱状图，
保存到 outputs/趋势.png，标题用英文（避免中文字体问题）。
```

**Skill 自动执行**：

1. 读 csv，确认有 `published_date` 列
2. 按 `YYYY-MM` 分组计数
3. 用 matplotlib 画柱状图：x 轴月份、y 轴篇数
4. 加标题、轴标签、单位
5. 保存到 `outputs/趋势.png`
6. 给出图表解读要点（最高峰、增长率、异常月份）

## 示例 2：分类分布饼图

```
用「出图」Skill 给 data/arxiv_clean.csv 的 category 列画一张分布图，
只画 Top 5 类别，其余合并为 "Other"，保存到 outputs/分类.png。
```

## 示例 3：分组对比箱线图

```
用「出图」Skill 画一张箱线图：
- x: model_size（small/medium/large）
- y: accuracy
- 数据：data/experiment_clean.csv
保存到 outputs/精度对比.png。
```

## 写 prompt 时记得带这些信息

| 信息 | 例子 |
| --- | --- |
| 数据文件 | `data/xxx.csv` |
| 图表类型 | 柱状图 / 折线图 / 散点图 / 箱线图 |
| x / y / 分组 | x=date, y=count |
| 保存路径 | `outputs/xxx.png` |
| 用途 | "论文配图" / "周报截图" / "课堂演示" |

写得越具体，Skill 跑得越准。
