## 任务 ↔ 工具

| 任务类型 | 首选 | 备选 | 理由 |
| --- | --- | --- | --- |
| 写一个新函数 / 单文件 | VS Code + Copilot 内联 | Claude Code IDE 模式 | 内联速度最快 |
| 跨多文件重构 | Claude Code | Codex CLI | 上下文最长、工具最稳 |
| 跑实验 / 数据脚本 | Claude Code | OpenClaw | 工具调用强、Skill 可复用 |
| 边写边问"为什么" | VS Code + Copilot Chat | Cursor | 内联体验最自然 |
| 长篇代码审查 | Claude Code（Sonnet 4.6 1M context） | Codex | 1M 上下文吃下整个项目 |
| 本地无网络环境 | Claude Code + Ollama / OpenClaw 接本地模型 | —— | 只剩离线方案 |
| 国内合规科研环境 | OpenClaw + DeepSeek | Cursor 切国产模型 | 国内服务稳定 |
| 学习 / 入门演示 | OpenClaw | Claude Code | 中文界面友好 |

## 一句话选型口诀

> "改单文件用 Copilot，重构和实验用 Claude Code，没网或国内用 OpenClaw。"
