# 选型决策 · 3 个真实场景

> 矩阵看不出选谁，用决策树 + 真场景跑一遍就清楚。

## 决策树（30 秒）

```
1. 多文件改 vs 单文件改？
   多 → Claude Code / Codex / OpenClaw
   单 → Cursor / Continue / VS Code+Claude

2. 能稳定连国外网吗？
   能 → 候选保留
   不能 → 只剩 OpenClaw + 国产 API / Continue+Ollama

3. 工具调用准确性敏感吗？(读文件 / 跑 shell / 改代码)
   敏感 → Claude Code > Codex > 其它
   不敏感 → 国产 + Cursor 够用

4. 涉密数据吗？
   是 → 强制本地（Ollama + Continue）
   否 → 走云端 API
```

## 场景 1：debug 师兄留下的 2000 行旧仓库

| 问题 | 答 |
| --- | --- |
| 多文件 / 单文件 | **多** |
| 国外网 | 能 |
| 工具调用敏感 | **极其**（要 grep + read + edit 反复横跳） |
| 涉密 | 否 |

→ **选 Claude Code（首选）/ Codex（备选）**

- 不选 Cursor：单文件级，跨文件追踪弱
- 不选 OpenClaw + DeepSeek：DeepSeek 工具调用稳定性弱于 Sonnet，调 bug 时会"假说我读了 file.py 其实没读"
- 不选 Codex 当首选：Codex 像精装修工（独立有界任务），Claude Code 像建筑队（反复读写大项目）

实测：同样 debug 任务，Claude Code 6-8 轮工具调用 vs Codex 10-15 轮。

## 场景 2：医院涉密临床数据本地分析

| 问题 | 答 |
| --- | --- |
| 多文件 / 单文件 | 单文件 .ipynb / .py |
| 国外网 | 不能 |
| 工具调用敏感 | 中等 |
| **涉密** | **是** |

→ **选 Continue (VS Code 插件) + Ollama 本地模型 (`qwen3.5:8b` 或更大)**

- 不选任何云端：付费 API 数据也要离开本地，伦理审查不过
- 不选 OpenClaw + DeepSeek：DeepSeek API 在云端
- 不选 Claude Code：默认连 Anthropic 服务器

注意：14B 量级本地模型基础数据分析够用，但**幻觉防御弱**，必须跑 `05_核验.py` 类回链脚本兜底。
有 A100 / H100 → `qwen3.5:30b-a3b` 或更大，质量接近 Sonnet 但完全离网。

## 短版决策（懒得跑决策树时用）

1. **改一坨文件 vs 一句话**？一坨 → Claude Code；一句话 → Cursor
2. **数据能见网吗**？能 → 云端最强；不能 → Ollama 本地
3. **中文比例 > 50%**？是 → 加 DeepSeek-V3 候选；否 → Sonnet 默认
