# 第 04 章 · VS Code、Codex、Claude Code 等 Agent 工具对比

> 对应 PPT 第 39–45 页

## WHAT —— 学什么

- **核心对象**：VS Code（IDE）、Codex（OpenAI 的代码任务代理）、Claude Code（命令行 Agent）、OpenClaw（国产前端）
- **真实场景**：要写一份代码任务，不知道该开哪一个工具
- **学习结果**：拿到一个新任务，能 30 秒内决定用哪个 Agent

## WHY —— 为什么学

- **痛点**：四五个工具来回切，每个都要登录、配 key、装插件，最后什么都没干完
- **边界**：本章只解决"选哪个"，不解决"怎么深入用某一个"

## HOW —— 怎么做（3 步）

1. **先按任务分型**：阅读 / 修改 / 调试 / 重构 / 自动化——不同任务最佳工具不同
2. **再选工具**：见 [工具对比矩阵.md](./工具对比矩阵.md)
3. **用小任务测试**：在真实项目里跑一遍同样的任务，看哪个最顺手
