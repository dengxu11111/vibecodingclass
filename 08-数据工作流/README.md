## 5 分钟先跑通这个

教室没网或 API 抽风？直接用预跑好的 10 条样例 CSV：

```powershell

```

有网想试真下载：`python 08-数据工作流/下载脚本.py --keyword "large language model" --limit 50`。

## WHAT —— 学什么

- **核心对象**：Dataset、API、清洗、缓存、图表、可复现输出
- **真实场景**：从公开数据或实验数据出发，完成“获取 → 清洗 → 分析 → 出图 → 记录”的闭环
- **学习结果**：能让 Agent 辅助搭建一个可复跑的数据分析流程，而不是只生成一次性图表

## WHY —— 为什么学

- **痛点**：科研分析最容易卡在路径、版本、缺失值和“这张图到底怎么来的”
- **边界**：本章关注流程可靠性，不追求复杂建模

## HOW —— 怎么做（5 步）

1. 明确数据来源、许可和更新频率
2. 固定原始数据、清洗数据和输出图表的目录
3. 让 Agent 先写最小可复跑脚本
4. 为每一步保存日志或摘要
5. 用验收清单确认结果可解释、可复现

## 推荐目录

```text
data/raw/          原始数据，只读保存
data/processed/    清洗后的中间数据
outputs/           图表、表格和报告草稿
notebooks/         探索性分析
scripts/           可复跑脚本
```

## 本章产出

- [下载脚本.py](./下载脚本.py)：从 arXiv 公开 API 抓论文 metadata
- [数据清洗.py](./数据清洗.py)：去重、规范列名、按日期排序并输出清洗报告
- [出图.py](./出图.py)：按月发文量和分类分布出图
- [验收清单.md](./验收清单.md)

## 怎么用

```powershell
cd 08-数据工作流
python 下载脚本.py --keyword "large language model" --limit 50
python 数据清洗.py
python 出图.py
```

输出默认写到仓库根目录的 `data/` 和 `outputs/`。这是课堂级示例；完整科研流水线见 [capstone-科研数据分析](../capstone-科研数据分析/)。
