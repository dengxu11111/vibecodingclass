# 常用 Prompt 模板

## 模型选型

```text
请根据下面任务帮我选择合适模型，并给出理由、风险和成本估算。

任务：
约束：
输入规模：
输出要求：

数据是否能上云：

请按“推荐模型 / 备选模型 / 不推荐模型 / 验证方法”输出。
```

## Vibe Coding 最小任务

```text
请在当前项目中完成一个最小可运行版本。

目标：
输入：
输出：
限制：
验收方式：

请先检查现有文件结构，再修改必要文件。完成后运行能证明结果的最小测试。
```

## 数据清洗

```text
请清洗这个数据文件：

文件路径：
关键字段：
去重规则：
缺失值规则：
输出路径：

要求保留原始文件，输出清洗摘要，并说明哪些问题需要人工确认。
```

## 论文阅读

```text
请阅读这篇论文/摘要，并按表格输出：

论文：
研究问题：
方法：
数据：
主要结论：
限制：
可引用证据：
需要人工核验的点：

不要编造引用；不确定的信息请标为“未确认”。
```
