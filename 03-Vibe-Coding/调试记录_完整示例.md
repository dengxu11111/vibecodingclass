# 调试记录 · 完整示例

> 这是 [调试记录模板.md](./调试记录模板.md) **跑完一个真任务**后的样子。
> 任务来自本仓库 capstone 的第一步：第一次跑 `01_下载.py`（Open-Meteo 路径）从崩到稳的全过程。

## 任务名

```
任务名：抓 Open-Meteo ERA5 7 城 5 年日均气温 → CSV
日期：2026-03-14
负责人：研究生 / 学员
```

## 输入

- 数据源：https://archive-api.open-meteo.com/v1/archive
- 数据规模：7 城 × 5 年 × ~365 天 ≈ 12782 行
- 限制条件：
  - Open-Meteo 单次请求最大跨度无明显限制（实测 30 年也能一次性返回）
  - 限速宽松，但课堂多人并发时建议 sleep ≥ 1 秒
  - 不需要 API key，无 token 限制
  - 中国大陆校园网到 archive-api.open-meteo.com **大部分时段直连可达**，少数时段需切节点

## Prompt 演进史

| 版本 | Prompt 关键词 | 用了哪个模型 | 输出问题 | 改进点 |
| --- | --- | --- | --- | --- |
| v1 | 「写个 Python 脚本抓 Open-Meteo 7 城气温」 | DeepSeek-V3 | 输出用了 `requests` 但代码没装；URL 参数把 latitude / longitude 都拼错 | 显式说"只用标准库 urllib"；给一条样例 URL |
| v2 | + "只用标准库 urllib；样例 URL: ..." | DeepSeek-V3 | 跑通，但 7 个城市循环里**没加 sleep**；连跑被 429 | 加 `time.sleep(1.0)` 每城之间 |
| v3 | + "每城之间 sleep 1 秒" | DeepSeek-V3 | 跑通；但 CSV 写入用了 `open(..., "w")` 默认 GBK，PowerShell 看是乱码 | 显式 `encoding="utf-8-sig"` |
| v4 | + "CSV 用 utf-8-sig 编码" | DeepSeek-V3 | ✓ 通过；写成本仓库 capstone/01_下载.py | 沉淀到仓库；后续 06 章封 Skill |

## 跑通的关键命令 / 关键错误

```text
# 第一次跑（v1 prompt 出来的代码）：
python 01_下载.py

# 出错信息：
Traceback (most recent call last):
  File "01_下载.py", line 3, in <module>
    import requests
ModuleNotFoundError: No module named 'requests'

# 解决：
让 AI 改成只用 urllib（v2 prompt），别引入 requests 依赖
```

```text
# 第二次跑（v2 prompt 出来的代码，没 sleep）：
python 01_下载.py
  抓 北京 ... 得 1826 天
  抓 上海 ... 得 1826 天
  抓 广州 ... 得 1826 天
  抓 西安 ... 抓取失败：HTTP Error 429: Too Many Requests

# 解决：
加 time.sleep(1.0) 每城之间（v3 prompt）
```

```text
# 第三次跑（v3 prompt，已加 sleep）：
python 01_下载.py
  ... 7 城全过
  [完成] 共 12782 条 → data/raw/era5_all.csv

# 用 PowerShell 打开 CSV：
Get-Content data/raw/era5_all.csv | Select-Object -First 3
锘縞ity,date,lat,lon,temp_c     ← 第一行有乱码"锘"，是 UTF-8 BOM 没识别

# 解决：
encoding 改成 "utf-8-sig"（v4 prompt），PowerShell 才能正确识别
```

## 沉淀

- **代码沉淀到**：`capstone-科研数据分析/01_下载.py`
- **prompt 沉淀到**：本课 [资源/常用prompt模板.md](../资源/常用prompt模板.md) 的"数据下载脚本生成"段
- **经验沉淀**：
  - 中国大陆课堂跑科研脚本，**默认就要 sleep**（哪怕 API 文档说限速宽松，多人并发就崩）
  - PowerShell + 中文环境下，CSV 一律 `utf-8-sig`，不要 `utf-8`
  - 写数据下载脚本，**第一句 prompt 就说"只用标准库 urllib"**，省后续装包麻烦

## 你的调试记录花了多久？

- 4 轮 prompt 迭代：每次写 prompt + 跑 + 看错 ≈ 5 分钟
- 总耗时：**约 25 分钟**

第一次做 Vibe Coding 节奏会感觉慢。**记得每次出错都记一笔——记到第 3 次同类问题时你就知道直接绕过哪些坑了。**

## 调试记录的元价值

Vibe Coding 的核心不是"AI 一次写对"——而是**让你下次写同类任务的时候 5 分钟就跑通**。

第一次抓 Open-Meteo 花 25 分钟；
但你把这条记录留下来，下次抓 NOAA / NASA Earthdata / GBIF 时，
**v1 prompt 就直接复制 v4 的形态**（"只用标准库 urllib + sleep + utf-8-sig + 样例 URL"），
一次性跑通的概率从 10% 跳到 80%。

这就是"AI 写、人记"的复利。
